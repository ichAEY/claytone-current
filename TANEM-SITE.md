# TANEM — быстрый выпуск сайта мастера

## Что редактировать

Для нового мастера не нужно искать данные по компонентам сайта.

1. Откройте `site-data.mjs`.
2. Замените данные мастера, контакты, адрес, ссылки, рейтинг, услуги, отзывы, акции и SEO.
3. Загрузите фотографии в `public/assets` и укажите их пути в `site-data.mjs`.
4. Проверьте изменения в отдельной ветке.
5. После проверки слейте изменения в `main` — GitHub Pages сам применит данные перед сборкой.

## Что не трогать без необходимости

- `app/mobile-claytone.tsx` — стабильный визуальный шаблон.
- CSS-файлы — дизайн и адаптив.
- `app/layout.tsx` — генератор сам обновляет SEO и данные карты перед сборкой.

## Как работает

`scripts/generate-site.mjs` берёт стабильную закоммиченную версию шаблона, подставляет данные из `site-data.mjs` и только после этого запускается сборка. Если ожидаемая часть шаблона не найдена, генератор завершает сборку с ошибкой вместо публикации частично сломанного сайта.
